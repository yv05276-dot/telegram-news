    הערוצים שלך

    המתג מסתיר או מציג ערוץ רק אצלך. מחיקה מוציאה אותו מהרשימה לגמרי.

      הוספת ערוץ

      מפתח גישה ל־GitHub

      כדי להוסיף ולמחוק ערוצים, ושהאפליקציה תתעדכן לבד, צריך מפתח, פעם אחת בלבד:
      1. פתח את דף יצירת המפתח ב־GitHub.
      2. ב־Token name כתוב: מבזק. ב־Expiration בחר No expiration.
      3. ב־Repository access בחר Only select repositories ואת telegram-news.
      4. ב־Permissions הוסף Contents ו־Actions, שניהם Read and write.
      5. לחץ Generate token, העתק את המפתח והדבק כאן.
